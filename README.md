# Mon Portfolio Personnel

Bienvenue sur mon portfolio personnel ! Ce site me permet de présenter mon parcours, mes compétences et mes projets de développement.

## 🚀 À propos de la template
Ce projet est basé sur la template open-source **Dark Minimal** créée par Gothsec.
* Lien de la template originale : [https://github.com/Gothsec/dark-minimal](https://github.com/Gothsec/dark-minimal)

## 🛠️ Technologies et Hébergement
Le site repose sur des technologies modernes et performantes :
* **Astro** (Framework web principal)
* **Tailwind CSS** (Pour le design et les styles)
* **GitHub Pages** (Pour l'hébergement et le déploiement en ligne)

## 📂 Structure du projet
Voici un aperçu rapide de l'organisation des dossiers à la racine :
* `public/` : Contient les fichiers statiques (comme mon CV au format PDF et les ressources externes).
* `src/` : Le cœur du code source du site.
  * `src/components/` : Les différents blocs et composants réutilisables.
  * `src/pages/` : Les pages principales du site (notamment `index.astro` pour la page d'accueil).
